Leyenda de estado

:id activa — la ruta { path: ':id' } existe y monta un componente de edición. Solo instalaciones y usuarios (más roles) la tienen.
placeholder — hay children: [{ path: '' }] pero la línea { path: ':id' } sigue comentada. Editar por ruta no funciona todavía.
plana — { path, component } directo, sin children. Solo listado.
especial — segundo nivel de edición o utilidades fuera del árbol de tabs (instalacionesespacios, instalacionesrutas, imagenes, mapa) y páginas de error.
